DNS Resolver Recommender

Measure and compare public DNS-over-HTTPS (DoH) resolvers directly from your browser to find the fastest option for your connection.

💡 Legend & Methodology

🏷️ Resolver Metadata Tags:
  • [DE/US/CH...] Country location of the server nodes.
  • DNSSEC: Supports Domain Name System Security Extensions (cryptographic verification).
  • No-Logs: Resolver guarantees no query logging for maximum privacy.
  • Unfiltered: Resolves all domains natively (no adblocking/content filters).
  • ⚠️ No-CORS: Server lacks CORS headers. Measured via opaque browser queries (unverified but fast).
📊 Best/Fastest Ranking:

Resolvers are ranked by a weighted Performance Score calculated as:
Score = 80% Cached + 20% Uncached

This reflects real-world browsing where 80-95% of queries are served from the cache, while 5-20% require recursive uncached resolution.
